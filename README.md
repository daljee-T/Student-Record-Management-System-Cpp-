# Student-Record-Management-System-Cpp-
Student Record Management System in C++ allowing add, view, search, delete, and sort of student records. Implements OOP, STL, and file handling for persistent storage with a menu-driven console interface.

**Description**
A console-based C++ application that allows users to efficiently manage student records. The system provides functionality to add, view, search, delete, and sort student records based on marks or name. All data is persisted using file handling, ensuring records are saved between program runs. The project demonstrates Object-Oriented Programming (OOP) principles, use of STL containers, and clean, menu-driven design.

**Features**
1. Add new student records (Roll No, Name, Marks)
2. View all existing records
3. Search for a student by Roll Number
4. Delete a student record by Roll Number
5. Sort records in descending order of marks
6. Save and load data from a text file

**Tech Stack**
1. C++
2. STL (vectors, algorithms)
3. File handling
4. Object-Oriented Programming
